Delegate -: It is a reference type which can hold an address of method/methods. It is a type safe and it follows OOPs concept.

Types of Delegates-: Unicast, Multicast

Predefine Delegates -:
	Action -: Return type is not there
	Funciton -: Return type is there
	Predicate -: Return type is there but in Boolean


Syntax to declare delegate -:
	Access_Modifier  Delegate_Keyword  Return_Type Name_of_Delegate(List of Parameters)
